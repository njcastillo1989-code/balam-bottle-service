BALAM BOTTLE SERVICE

1. Crear repositorio público nuevo en GitHub: balam-bottle-service.
2. Subir index.html, styles.css, app.js, menu-data.json, .nojekyll y carpeta assets/ (carta-original.jpeg).
3. Settings > Pages > Deploy from a branch > rama principal del nuevo repositorio > /root > Save.
4. URL esperada cuando esté publicado: https://njcastillo1989-code.github.io/balam-bottle-service/
5. Abrir editor.html de forma privada (NO subirlo al repositorio público). Ingresar token Fine-grained con Contents read/write SOLO para el repositorio nuevo. Dejar rama vacía para autodetección.
6. Al guardar, se actualiza menu-data.json. El QR debe generarse solo después de confirmar la URL real publicada.
7. Precios transcritos exactamente de la imagen proporcionada; revisar antes de publicar.
8. No se incluye conversión automática MXN/USD.
